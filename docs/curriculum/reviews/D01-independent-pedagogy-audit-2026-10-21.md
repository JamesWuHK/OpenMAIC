# D01 六课独立教学审查（2026-10-21）

## 总判定

**整体 BLOCK：六课目前均不可标记为可导入／可发布。** D01-01 至 D01-05 为 FIX；D01-06 为 BLOCK。此结论基于逐课源教案、设计合同及 `20261012-r02` 候选 JSON/HTML 的只读审阅，不等同浏览器运行或课堂试教。

共同硬缺口：候选 PBL 项目的 `submissions` 与 `evaluations` 初始为空。scene-05 至 scene-09 的支援互动提示学生把结果交回对应里程碑，但没有已验证的结果桥接进入 PBL submission；scene-04 签名互动亦缺少回交提示。另经核对 `lib/utils/iframe.ts`，安全沙箱把 iframe 的 `localStorage` API 替换成 iframe 生命周期内存储，无法作为页面刷新后的持久化证据。因此“同一学生作品从 v01、证据评议、学生决定 v02 到展示”的闭环尚未建立或运行验证。界面调用 `localStorage` 或出现保存提示，均不等于 PBL 项目已保存作品证据。

## 未覆盖的验收范围

本次未操作实际浏览器中的 PBL 项目，也未验证提交、里程碑锁定／解锁、刷新恢复或作品修订；未进行学校 Astra／Blender 环境实跑、课堂计时、完整人工听音或学生试教。组件级 QA 和静态审查不能替代这些门槛。30 分钟仍是未验证的全学习路径目标，不代表播放器运行时或已测得课堂时间。
